🎯 Match-3 Goal Solver

Upload a screenshot, mark the board, set the goals, then rank moves by goal progress.

1. Screenshot and board area

Fixed screenshot zones: board X 42–1030 / Y 860–1839; goals X 599–814 / Y 248–448; moves X 867–1056 / Y 210–409. Green = goals, amber = moves. Screenshot size is fixed at 1080 × 2340 px.

2. Board editor

Tap a cell to cycle through colors, obstacles, and empty cells.

3. Goals

Enter remaining target counts. Leave other colors at zero.

4. Search

Prototype limitations: goal counters are entered manually; tile recognition is a color estimate; obstacles and gravity use simplified rules. Special pieces, chained effects, portals, and game-specific refill rules are not modeled yet.
